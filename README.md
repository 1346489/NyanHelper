# 本喵助手 (Benmao Assistant)

一个可爱的粉色主题 Android 悬浮窗工具应用，提供文本替换、视觉效果、主题自定义等功能。

> 🐱 本应用完全公益免费，如果你花钱买了，恭喜你被骗啦~

## ✨ 功能特性

### 🏠 主页
- 显示当前状态（已就绪）
- 模式：Shizuku
- 一键启动悬浮窗
- 运行日志展示

### 🔐 权限管理
- **无障碍权限**：用于文本替换功能（"喵"字添加、"我"→"本喵"、"你"→"主人"）
- **悬浮窗权限**：允许应用在其他应用上层显示

### ⚙️ 设置
- 深色模式开关

### 🎯 悬浮窗菜单
点击悬浮球打开菜单，包含以下页面：

#### 📢 公告
1. **此应用公益，不要被骗了**
2. 使用说明与更新信息

#### 🔧 功能（原"注入"）
通过无障碍权限实现三个文本替换开关：
- ✅ 始终在结尾添加"喵"字
- ✅ 将"我"自动换为"本喵"
- ✅ 将"你"自动换为"主人"

#### 🎨 设置（原"视觉"）
- **雪花**：在悬浮窗内飘落 ❄️
- **流星雨**：在悬浮窗内划过 ☄️
- 两个效果互斥，只能开一个

#### 🎮 控制
- **音量键隐藏**（默认开启）
  - 音量上键：将悬浮球恢复为菜单
  - 音量下键：将菜单缩回悬浮球

#### 🖌️ 主题
- **背景颜色**（3种）：白色、粉色、深色
- **文字颜色**（3种）：黑色、白色、紫色
- **恢复默认主题**：白色背景 + 黑色文字

### 🐾 悬浮球
- 可拖动移动位置
- 点击展开为完整菜单（带动画）
- 菜单右上角 X 按钮缩回为悬浮球

## 🏗️ 技术架构

```
app/src/main/
├── java/com/benmao/assistant/

│   │   ├── overlay_menu.xml           # 悬浮窗菜单布局

```

## 🚀 构建与安装

### 环境要求
- Android Studio Hedgehog (2023.1.1) 或更高
- Android SDK 34
- JDK 17

### 构建步骤
1. 克隆仓库
   ```bash
   git clone https://github.com/yourusername/BenmaoAssistant.git
   cd BenmaoAssistant
   ```

2. 用 Android Studio 打开项目

3. 同步 Gradle

4. 运行到设备或模拟器（Min SDK 21）

### 手动构建
```bash
./gradlew assembleDebug
# APK 输出到 app/build/outputs/apk/debug/
```

## 📱 使用说明

1. **首次启动**：应用会自动跳转到主页
2. **开启权限**：点击底部"权限"标签
   - 开启无障碍权限（找到"本喵助手"并启用）
   - 开启悬浮窗权限
3. **启动悬浮窗**：回到主页点击"启动悬浮窗"按钮
4. **使用功能**：
   - 点击粉色悬浮球展开菜单
   - 在"功能"页面开启需要的文本替换
   - 在"设置"页面开启雪花或流星雨效果
   - 在"主题"页面自定义颜色
5. **音量键控制**：
   - 音量上：悬浮球 → 菜单
   - 音量下：菜单 → 悬浮球
